EXECUTIVE DEMO GUIDE / HOW TO READ THIS PROTOTYPE

From wildfire signal to insurer action

This guide explains how to use the radar, what its terms mean, where the observations come from, and how the planning estimates are produced.

Important distinctionDemo mode presents a curated historical case and an illustrative portfolio. Live mode presents current source observations when available. Exposure, loss, claims, and reinsurance figures are planning estimates—not live insured data or actuarial results.
START

How to use the radar

Move from the regional overview to event detail, portfolio exposure, scenarios, and recommended actions. Select an event to keep the same case in focus as you move between screens.

Begin with the overview

Risk Radar shows active event candidates, nearby policy counts, and potentially exposed total insured value. Select an event row or map marker to investigate it.

Explain the signal

Event Intelligence brings together fire detections, weather, wind, official warnings, source freshness, risk, confidence, and trend. Select Why? for the component breakdown.

01

Start with Risk Radar

Use this as the regional overview. The top cards answer “how many events, and how much portfolio could be nearby?” Select an event to move into detail.

Observed signals

Fire detections, warning areas, and event markers represent reported or observed signals. They are not the same as a confirmed fire perimeter.

Threat envelope

Dashed amber geometry is a directional planning envelope based on wind assumptions. It is a what-if area, never a predicted fire perimeter.

Timeline

In Demo mode, move through historical snapshots to see how detections, warnings, risk, confidence, exposure, and planning outputs change over time.

02

Inspect Event Intelligence

This is the explainability view. It shows which signals support the assessment and how fresh each source is.

Risk score25% active fire + 20% weather + 15% wind + 15% warning + 10% vegetation/fuel + 10% growth + 5% corroborationEach component is scored from 0–100 and the weighted result is clamped to 0–100. Risk is severity of the signal mix—not probability of spread or a loss estimate.

Confidence

Confidence reflects independent supporting evidence and recency. It is not a probability that the event will spread.

Trend

Trend compares the selected snapshot with the previous snapshot and reports increasing, stable, or decreasing. It is not a forecast.

Source freshness

Freshness indicates how recently the supporting observation was received. A recent observation can still be incomplete or uncertain.

SOURCES

What the sources are used for

The radar combines independent public sources so users can compare direct fire observations, environmental conditions, official warnings, and broader fire context.

NASA FIRMS

Satellite active-fire detections with location, acquisition time, confidence, and fire radiative power. Used to identify activity, support growth, and show nearby detections.

DWD

German weather and fire-danger information, including temperature, humidity, wind, gusts, and precipitation context. Used for weather and wind components and to orient scenarios.

NINA

Official German warning information, including warning level, affected area, message, and timestamp. Used to corroborate the signal and show warning geometry.

EFFIS / Copernicus

European fire and burned-area context. Used as independent corroboration and to add broader environmental context around an event.

Reading the evidenceNo single source proves the full situation. The strongest assessment comes from agreement across sources; missing or delayed observations reduce confidence.
03

Move to Portfolio Impact

The portfolio is an illustrative synthetic residential portfolio distributed around NRW population centres and the showcase event. It demonstrates how an insurer could view concentration without exposing individual policy locations.

Distance bands

Policies are grouped by distance from the event centroid: event area, 0–1 km, 1–3 km, 3–5 km, and 5–10 km.

TIV

Total insured value is the sum of building and contents values for the selected group. It describes the amount of insurance at stake, not the expected loss.

Exposure

Policies are counted as exposed when their locations fall inside the selected directional scenario envelope. The overview also shows distance-based proximity.

Compare Scenario & Reinsurance

Use scenarios to test how a wider or more severe directional envelope changes exposed policies, TIV, indicative loss, claims, and treaty status.

The envelope is oriented using the reported wind direction. It is a planning assumption, not a fire-behaviour or propagation model.

05

Understand the planning estimates

The application turns scenario exposure into ranges to support early coordination. These outputs are deliberately indicative.

Indicative insured loss

Applies configured loss ratios to TIV inside the event area and to the remaining policies inside the scenario envelope. The result is a low-to-high planning range.

Expected claims

Applies configured claim probabilities to the same groups of policies. The result is an estimated claim-volume range, not a claims decision.

Reinsurance status

Compares the loss range with a synthetic €50m retention and €100m limit. “Potentially attaches” means only that part of the range crosses the retention.

Use the ranges correctlyLoss, claims, staffing, and reinsurance figures support preparedness conversations. They are not a substitute for underwriting, claims adjustment, catastrophe modelling, or treaty interpretation.

LIVE

How live mode works

Live mode uses the latest available observations from the configured source feeds instead of the curated Demo mode case. It can surface current event candidates across the region and updates the source timestamp shown in the radar.

Current observations

FIRMS and NINA observations help identify current candidates. DWD and EFFIS add weather, warning, and environmental context for the selected event.

Refresh the view

Select Refresh live when you want to request a new source snapshot. The event list, source indicators, risk, maps, and exposure view update from the latest available information.

Read limitations

Public feeds can be delayed, incomplete, or unavailable. An affected source is marked and the view may use the latest available reference information; check source freshness before acting.

Demo and live are different viewsDemo = curated case + historical replay · Live = current source observations + live historyLive mode still uses the illustrative portfolio and planning assumptions described above. It does not provide real policy exposure or a scientific fire-spread forecast.
DATA

What is observed, modelled, and illustrative?

Observed or curated signal

Source observations, warning information, event definitions, and historical snapshots used to describe the hazard situation.

Illustrative portfolio

Residential policies, TIV, concentration, action workload, and other portfolio values are synthetic examples for decision-support demonstration.

Planning calculation

Risk, scenarios, exposure, loss ranges, claim ranges, and reinsurance awareness are transparent planning calculations based on the inputs shown.

Prototype boundaryThe radar does not provide real policyholder data, automated claims decisions, actuarial calibration, treaty advice, or a scientific wildfire propagation model.
