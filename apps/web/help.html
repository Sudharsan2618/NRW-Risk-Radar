EXECUTIVE DEMO GUIDE / HOW TO READ THIS PROTOTYPE

From wildfire signal to insurer action

This guide explains what each screen shows, where the numbers come from, and which outputs are simulated planning estimates.

Important distinctionThe historical Hürtgenwald event and source observations are curated demo fixtures. The portfolio, scenario envelopes, losses, claims, and reinsurance outputs are deterministic synthetic calculations—not live insured data or actuarial results.
01

Start with Risk Radar

Use this as the NRW overview. The top cards answer “how many events, how much portfolio could be nearby?” Select the Hürtgenwald row to move into event detail.

Observed layers

NASA FIRMS points are individual satellite fire detections. NINA warning geometry and the Hürtgenwald event marker are observed or curated known signals.

Scenario layer

Dashed amber geometry is a directional threat envelope. It is an assumption-based what-if area, never a predicted fire perimeter.

Replay timeline

Move through the four stored snapshots. Fire detections, warning state, risk, confidence, exposure, and planning outputs change as the event escalates.

02

Inspect Event Intelligence

This is the explainability screen. Click Why? next to Risk to see the seven component scores and inspect source freshness in the provenance panel.

Risk score25% active fire + 20% weather + 15% wind + 15% warning + 10% vegetation + 10% growth + 5% corroborationEach component is normalized to 0–100 and the weighted result is clamped to 0–100.

Risk

Severity of the hazard signal mix. It is not probability of spread and not a loss estimate.

Confidence

Independent source corroboration score: FIRMS, EFFIS, DWD, NINA, local confirmation, and recency each contribute explicit points.

Trend

Compares the selected replay risk score with the previous stored snapshot. It is increasing, stable, or decreasing—not a forecast.

03

Move to Portfolio Impact

The portfolio contains 25,000 deterministic synthetic residential policies concentrated around NRW cities and deliberately around Hürtgenwald so the demo has meaningful exposure.

Privacy-aware display

The overview uses concentration bubbles rather than exposing policy markers. This is synthetic data, but the UI follows an enterprise privacy pattern.

Distance bands

Policies are grouped by haversine distance from the event centroid: event area, 0–1 km, 1–3 km, 3–5 km, and 5–10 km.

TIV

Total insured value is building TIV plus contents TIV from the generated portfolio. It is summed exactly for the selected group.

04

Compare Scenario & Reinsurance

Current, Adverse, and Severe immediately change the directional envelope, intersected policies, TIV, indicative loss, claims range, and treaty status.

Current2 km spread / 1 km crosswind
Adverse5 km spread / 2 km crosswind
Severe10 km spread / 4 km crosswind

Loss uses configurable synthetic ratios. Claim volume uses configurable claim probabilities. Reinsurance uses a synthetic €50m retention and €100m limit. “Potentially attaches” means the calculated high end crosses the retention; it does not mean a treaty claim is certain.

05

Use the Preparedness Action Center

Translate the selected planning range into accountable work for Claims, Customer Operations, Reinsurance, and Finance. Status changes persist locally in the demo.

Signal→Exposure→Planning range→Team action
DATA

What is real, simulated, or live?

Curated fixture

Historical Hürtgenwald event definition, FIRMS-like observations, DWD weather, NINA warning, EFFIS context, and replay snapshots.

Synthetic calculation

25,000 policies, scenario geometries, exposure aggregation, loss ranges, claims, staffing implications, and reinsurance awareness.

Live connector

In live mode, configured FIRMS/DWD/NINA/EFFIS URLs are attempted. Each source falls back to its fixture when unavailable, and the sidebar reports fallback status.

Prototype boundaryNo scientific fire propagation model, real policyholder PII, actuarial calibration, automated claims decisions, or production insurer integration is present.
